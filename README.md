# Tic-Tac-Toe

A simple browser-based Tic-Tac-Toe game for two players.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Two-player O and X gameplay
- Winner detection
- Draw/tie detection
- Reset/restart button

## How to Run

Open `index.html` in a web browser.

## How to Play

Players take turns selecting an empty cell. O starts the game. The first player to place three matching marks in a row, column, or diagonal wins. If all nine cells are filled without a winner, the game is a draw. Use the reset button to start again.
